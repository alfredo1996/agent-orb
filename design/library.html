Component library: today and proposed

Left: each component as the studio draws it today, rendered from its own stylesheet and real markup. Right: the same component in the approved Live v3 language. Under each row: what changes and what could break. The page kit comes after the library.

No test reads the markupThe studio has no DOM or end-to-end tests. Its seven test files check pure logic, so class names, markup and row heights can change freely.
What can break silentlySVG text drawn at fixed positions sized for today's font: the Ledger tooltip, Pipeline and Skills nodes, the Office. The layout tests assert node sizes 190×94 and 176×58.
Names that stayThe model tones opus, sonnet, haiku and their CSS variables, which the code reads. The 700px phone breakpoint, which the JS and the CSS share.
Dead CSS to deleteLive v1 leftovers that nothing renders: .session, .flag, .tree, .term and others. A stray .k colours Analysis numbers purple by accident.
